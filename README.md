# 구독정리함

> 구독 서비스의 결제일과 무료체험 종료일을 놓치지 않도록 미리 알림으로 알려주고, 월 구독료·결제 경로 차액·중복 구독을 정리해 주는 앱

- **과목:** iOS 프로그래밍 (SwiftUI 기반) 기말 프로젝트
- **기반:** 수업 교재 StudyBuddy를 발전시킨 나만의 앱
- **작성자:** 김동우 (2022261009)
- **개발 환경:** Xcode, SwiftUI, SwiftData, iOS 시뮬레이터

---

## 1. 해결하려는 문제

- 무료체험이 끝난 줄 모르고 있다가 **자동결제**가 된다.
- 구독이 여러 개라 **언제, 얼마가 빠져나가는지** 한눈에 보기 어렵다.
- 같은 서비스를 **다른 아이디로 중복 구독**하고 있는 줄 모른다.
- 아이폰 앱(인앱)으로 결제하면 웹 결제보다 **더 비싸게** 내고 있을 수 있다.

구독정리함은 이 문제를 **결제 전 미리 알려주는 것**에 집중한다.

## 2. 주요 기능

### 2.1 구독 등록·관리
| 기능 | 설명 |
|---|---|
| 구독 추가 | 서비스명, 요금제, 요금, 결제 주기, 결제일, 무료체험 종료일, 결제 경로, 공유 인원, 가입 계정 입력 |
| 구독 수정 | 요금 인상·요금제 변경·결제일 변경 반영 |
| 구독 삭제 | 목록에서 스와이프 삭제 |
| 구독 목록 | 다음 결제일이 가까운 순으로 정렬 |
| 데이터 저장 | SwiftData로 저장, 앱을 껐다 켜도 유지 |

### 2.2 간편 입력 (프리셋)
- 인기 서비스 프리셋: 넷플릭스, 유튜브 프리미엄, 쿠팡와우, 티빙, 디즈니+ 등
- 요금제 선택: 예) 넷플릭스 광고형 스탠다드 / 스탠다드 / 프리미엄
- 결제 경로 선택: 웹·안드로이드 결제 / 아이폰 앱(인앱) 결제
- 선택에 맞는 요금 자동 입력 (요금 변경 시 직접 수정 가능)
- 요금 기준일 표시 (예: "2026년 11월 기준 요금")

### 2.3 결제 일정
- **결제 주기 선택:** 매월 / 매년
- **다음 결제일 자동 계산:** 오늘 날짜와 결제일을 비교해 다음 결제일을 구함
  - 예) 오늘이 18일, 결제일이 5일 → 다음 결제일은 다음 달 5일
- **결제 예정 안내:** "12월 5일 넷플릭스 스탠다드 13,500원 결제 예정"
- **결제 임박 색상 표시**
  - 🔴 오늘 결제
  - 🟠 내일 결제
  - ⚫ 무료체험 지남 (자동결제 위험)
- **무료체험 D-day:** "체험 종료까지 3일"

### 2.4 결제 캘린더
- 주간 캘린더에 요일별 결제 예정 구독 표시
- 정렬: 결제일순 / 금액순
- 필터: 카테고리(영상·음악·쇼핑·클라우드) / 결제 주기(월간·연간) / 결제 경로(웹·앱)
- 정렬과 필터 조합 사용 가능 (예: "영상 카테고리 + 금액 높은 순")

### 2.5 알림 (로컬 알림)
- 알림 권한 요청
- **결제 N일 전 알림:** "3일 뒤 넷플릭스 스탠다드 13,500원이 결제돼요"
- **무료체험 종료 알림:** "내일 무료체험이 끝나요. 해지하려면 오늘 하세요"
- 알림 시점 설정: 1일 / 3일 / 7일 전 (기본 3일 전)
- 구독별 알림 켜기/끄기
- 발표용 "10초 뒤 테스트 알림" 버튼

> 원격 푸시 알림(유료 개발자 계정 필요)이 아닌 `UNUserNotificationCenter` 기반 **로컬 알림**을 사용한다.

### 2.6 계정 관리와 중복 구독 경고
- 가입 계정 등록: **계정 아이디(이메일 등)만 저장, 비밀번호는 저장하지 않음**
- 계정별 구독 목록과 월 금액
- **중복 구독 경고:** 같은 서비스를 서로 다른 계정으로 구독 중이면 경고
  - 예) "넷플릭스를 2개 계정으로 구독 중이에요 (월 27,000원). 하나를 해지하면 월 13,500원 절약"
- 같은 서비스·같은 계정으로 다시 등록하면 "이미 등록된 구독이에요"로 차단

### 2.7 계산·통계
- 월 구독료 합계
- 연간 예상액 (월 합계 × 12)
- 연간 구독 월 환산 (연 요금 ÷ 12)
- 1인당 요금 (요금 ÷ 공유 인원)
- 결제 경로 차액: "웹으로 결제하면 월 4,600원 절약"
- 연간 절약 가능액: 인앱 결제 구독의 차액 합계 × 12

### 2.8 요약 대시보드
- 이번 달 요약: 구독 개수, 월 합계, 연간 예상액, 이번 주 결제 예정
- 계정별 요약: 계정마다 구독 수와 월 금액
- 절약 제안: 결제 경로 변경, 중복 구독 해지
- 빈 상태 안내: 구독이 없으면 "첫 구독을 추가해보세요" (`ContentUnavailableView`)

## 3. 도전과제 계약 (★8)

| ID | 트랙 | 점수 | 도전과제 | 이 앱에서 구현하는 내용 | 완료 기준 (시연·검증) |
|---|---|---|---|---|---|
| C1 | C 일정·마감 | ★1 | 마감 임박/지남 항목 색상 표시 | 결제일·무료체험 종료일 기준 색상 표시 | 오늘·내일·지남 3단계 구분 |
| C2 | C 일정·마감 | ★2 | 마감일순 정렬·필터 + 주간 캘린더 보기 | 결제 캘린더, 결제일순·금액순 정렬, 카테고리·주기·경로 필터 | 정렬/필터 조합 동작 시연 |
| E2 | E 나만의 도메인 전환 | ★2 | 도메인 고유 계산 + 통계 | 월 합계, 연간 예상액, 연→월 환산, 1인당 요금, 결제 경로 차액 | 계산 결과를 손계산과 대조 |
| E3 | E 나만의 도메인 전환 | ★3 | 2개 이상 모델 관계(@Relationship) + 요약 대시보드 | 계정(Account) ↔ 구독(Subscription) 관계, 계정별 요약·중복 구독 경고 대시보드 | 삭제 시 연관 데이터 처리 설명 |

**합계: ★8 (기준 ★4 이상 충족)**

### E3 삭제 규칙
- 계정을 삭제하면 그 계정에 연결된 구독도 함께 삭제한다 (`deleteRule: .cascade`).
- 이유: 계정이 없어진 구독은 관리할 대상이 없으므로, 남겨두면 주인 없는 데이터가 된다.

### E2 손계산 예시
| 항목 | 계산 | 결과 |
|---|---|---|
| 연간 구독 월 환산 | 99,000 ÷ 12 | 8,250원 |
| 결제 경로 차액 | 19,500 − 14,900 | 월 4,600원 |
| 연간 절약 가능액 | 4,600 × 12 | 55,200원 |
| 1인당 요금 | 17,000 ÷ 4 | 4,250원 |

## 5. 데이터 모델

```swift
enum BillingCycle: String, Codable {
    case monthly   // 매월
    case yearly    // 매년
}

enum PaymentRoute: String, Codable {
    case web       // 웹·안드로이드 결제
    case inApp     // 아이폰 앱(인앱) 결제
}

@Model
final class Account {
    var accountID: String              // 가입 계정 아이디 (비밀번호는 저장하지 않음)
    var memo: String

    @Relationship(deleteRule: .cascade, inverse: \Subscription.account)
    var subscriptions: [Subscription] = []

    init(accountID: String, memo: String = "") {
        self.accountID = accountID
        self.memo = memo
    }
}

@Model
final class Subscription {
    var name: String                   // 서비스명 (넷플릭스)
    var planName: String               // 요금제 (스탠다드)
    var fee: Int                       // 결제 금액
    var billingCycle: BillingCycle     // 매월 / 매년
    var billingMonth: Int?             // 매년 결제일 때 결제 월
    var billingDay: Int                // 결제일 (1~31)
    var trialEndDate: Date?            // 무료체험 종료일 (없으면 nil)
    var paymentRoute: PaymentRoute     // 웹 / 인앱
    var sharedCount: Int               // 공유 인원 (혼자면 1)
    var category: String               // 영상, 음악, 쇼핑, 클라우드
    var notifyEnabled: Bool            // 알림 켜기/끄기
    var notifyDaysBefore: Int          // 며칠 전 알림 (1, 3, 7)
    var account: Account?              // 가입 계정

    init(name: String, planName: String, fee: Int,
         billingCycle: BillingCycle = .monthly, billingMonth: Int? = nil,
         billingDay: Int, trialEndDate: Date? = nil,
         paymentRoute: PaymentRoute = .web, sharedCount: Int = 1,
         category: String, notifyEnabled: Bool = true,
         notifyDaysBefore: Int = 3, account: Account? = nil) {
        self.name = name
        self.planName = planName
        self.fee = fee
        self.billingCycle = billingCycle
        self.billingMonth = billingMonth
        self.billingDay = billingDay
        self.trialEndDate = trialEndDate
        self.paymentRoute = paymentRoute
        self.sharedCount = sharedCount
        self.category = category
        self.notifyEnabled = notifyEnabled
        self.notifyDaysBefore = notifyDaysBefore
        self.account = account
    }
}
```

**StudyBuddy에서 바뀐 점**
- `StudyTask` → `Subscription`으로 도메인 전환
- 12장 `dueDate`(마감일) 개념 → 결제일·무료체험 종료일
- 모델 1개 → `Account` ↔ `Subscription` 2개 모델 관계

## 6. 보안·개인정보 설계

- **카드 정보를 저장하지 않는다.** 카드 결제 내역 자동 연동은 금융 마이데이터 허가 사업자만 가능하고, 카드 정보 저장은 보안 위험이 크므로 직접 입력 방식을 택했다. 대신 프리셋으로 입력 부담을 줄였다.
- **비밀번호를 저장하지 않는다.** 중복 구독 확인에 필요한 계정 아이디만 저장한다.
- 모든 데이터는 기기 안(SwiftData)에만 저장한다.

## 8. 발표 시연 시나리오 (7분)

1. 문제 제기: "무료체험 끝난 줄 모르고 결제된 적 있으시죠?"
2. 프리셋으로 넷플릭스·유튜브 프리미엄·연간 구독 등록
3. 결제 임박 색상(오늘·내일·지남) 확인 — C1
4. 결제 캘린더에서 정렬·필터 조합 — C2
5. 테스트 알림 수신 확인
6. 대시보드: 월 합계·결제 경로 차액을 손계산과 대조 — E2
7. 다른 계정 중복 구독 경고, 계정 삭제 시 구독 함께 삭제(cascade) 설명 — E3
